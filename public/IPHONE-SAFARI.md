# UMBRA ROMÂNIEI - Instruțiuni Speciale iPhone/Safari

## 📱 PROBLEMĂ: 404 pe iPhone Safari

**SOLUȚIE IMEDIATĂ:**

### **1. URL-UL CORECT FĂRĂ HTTPS**
```
umbra-romanian-game.kliv.site
```

**NU:**
- ❌ https://umbra-romanian-game.kliv.site (poate da eroare pe Safari)
- ❌ www.umbra-romanian-game.kliv.site

**CORECT:**
- ✅ `umbra-romanian-game.kliv.site` (fără https://)
- ✅ `umbra-romanian-game.kliv.site/` (cu slash la final)

### **2. PE SAFARI IPHONE:**

#### **Metoda 1 - Direct în Address Bar:**
1. **Tap pe address bar** sus
2. **Type:** `umbra-romanian-game.kliv.site`
3. **Tap Go**
4. **Nu adăuga https://**

#### **Metoda 2 - Link test:**
1. **Trimite-ți acest link pe WhatsApp/Messenger:**
   ```
   umbra-romanian-game.kliv.site
   ```

2. **Deschide link-ul direct din aplicație**

### **3. DACĂ NU MERGE - VERIFICĂ:**

#### **A. Curăță Cache Safari:**
1. **Settings → Safari**
2. **Clear History and Website Data**
3. **Close and reopen Safari**

#### **B. Verifică Conexiunea:**
1. **Intră în Settings → WiFi**
2. **Asigură-te că ești conectat**
3. **Deconectează și reconectează**

#### **C. Încearcă alt browser:**
- **Chrome pentru iPhone**
- **Firefox pentru iPhone**

## 🔧 DACĂ PROBLEMA PERSISTĂ

### **Soluția Rapidă - Force Reload:**
1. **Reload page** (buton refresh)
2. **Force reload** (meniu → reload pagină)

### **Debugging:**
1. **Deschide Console:** Settings → Safari → Advanced → Web Inspector
2. **Caută erori roșii**
3. **Scrie-mi eroarea exactă**

## 📱 OPTIMIZĂRI PENTRU IPHONE

### **Add to Home Screen:**
1. **Deschide jocul în Safari**
2. **Tap Share button** (pătrat)
3. **Scroll down → Add to Home Screen**
4. **Add → Done**
